采用流式的方式解析JSON

## 查询处理
每解析一个元素 流式回调一个函数，
用一个定长的数组 char currpath[512]（512 bytes）保存当前路径。所以搜索深度不能超过512个字符。
搜索结果和搜索条件用一个结构体保存
struct path_result{
    char * search_path;
    char * value;
    uint8_t found;
}

处理JSON时
LEVEL[]  记录每一层的类型
state
遇到 '{' 时，调用 on_object_start() LEVEL[level++]=OBJECT 更新 currpath
遇到 '}' 时，调用 on_object_end() level-- 更新 currpath
遇到 '[' 时，调用 on_array_start() LEVEL[level++]=ARRAY 更新 currpath
遇到 ']' 时，调用 on_array_end() level-- 更新 currpath
遇到 ':' 时，判断  state= start_value 
遇到 '"' 时，调用 在OBJECT 中，state=ready 时 state=start_key 调用on_key_start() , state=start_key 时 key 读取完毕 调用on_key_end() 更新 currpath，state=start_value， 在ARRAY 中，state=ready 时 state=start_value 调用on_value_start() ,当  state==start_value时，value 读取完毕 更新 currpath 调用 on_value_end()
遇到 ',' 时 ，LEVEL[level]== OBJECT 时 state=ready ，LEVEL[level]== ARRAY 时 state=ready 

当读完的值为基础数据类型时（String，Number，boolean，null），调用下面两个基础函
void callbackproerty(char * currpath, char *value,path_result *[] serch_path);
currpath 与 path_result.search_path 匹配时，说明找到了结果。path_result.value 赋值为value;found=1;
void callbackarray(char * currpath, char *value ,path_result *[] serch_path )
currpath 与 path_result.search_path 匹配时，说明找到了结果。path_result.value 赋值为value;found=1;
处理到下一个元素时修改currpath的序号 如"info.list[0]" 改为"info.list[1]" 
这样处理，可以处理任意深度的json
